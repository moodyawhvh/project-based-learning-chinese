## 📖 项目简介

这是一个在 GitHub 上拥有数十万 Star 的知名教程清单项目，收录了上百个"从零开始构建完整应用"的编程实战教程。与照着文档敲语法不同，这里的每个教程都围绕一个真实项目展开：写操作系统、写编译器、写数据库、克隆知名 App、训练机器学习模型等。原清单按编程语言（C/C++、C#、Go、Java、JavaScript、Python、Rust、Swift 等 20 多种）分类整理，本仓库提供其核心内容的中文导览。

## ✨ 主要特性

- **项目驱动学习**：全部教程以"做出一个完整东西"为目标，而不是零散的语法讲解
- **覆盖 20+ 编程语言**：C/C++、C#、Clojure、Dart/Flutter、Elixir、Erlang、Go、Haskell、Java、JavaScript、Kotlin、Lua、PHP、Python、Ruby、Rust、Scala、Swift 等均有独立章节
- **从入门到硬核全覆盖**：既有 Todo List、天气 App 这类新手项目，也有手写操作系统、编译器、TCP/IP 协议栈、调试器、Redis 等硬核工程
- **紧跟主流技术栈**：React、Vue、Angular、Next.js、Node.js、Django、Flask、Spring Boot、Flutter、机器学习与数据科学专题一应俱全
- **社区持续维护**：原项目有自动化链接巡检（link rot sweep），教程链接持续修复更新
- **游戏开发专题**：俄罗斯方块、打砖块、Flappy Bird、OpenGL 2D/3D 游戏、NES 红白机游戏等大量游戏实战
- **中文化导览**：本仓库将章节结构与代表性教程说明译为中文，降低英文清单的阅读门槛

## 🚀 快速开始

1. 打开原项目仓库：https://github.com/practical-tutorials/project-based-learning
2. 在 `README.zh-CN.md` 中浏览中文导览，确定想主攻的编程语言方向（如 Python、Go、JavaScript）
3. 进入原 README 对应语言章节，挑选一个与自身水平匹配的教程，点击链接进入原文学习
4. 建议新手从"Todo List / 天气 App / 博客"类小项目起步，进阶者可直接挑战"写编译器 / 写操作系统 / 手写 Redis"
5. 想收藏或贡献教程时，Fork 原仓库并阅读其 [CONTRIBUTING.md](https://github.com/practical-tutorials/project-based-learning/blob/master/CONTRIBUTING.md) 提交 PR
